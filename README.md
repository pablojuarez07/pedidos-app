# Cuatro Coronas

Aplicación web full-stack con arquitectura desacoplada (Frontend + Backend), que integra:

- 🔐 Autenticación JWT
- 📦 API REST
- ⚡ WebSockets en tiempo real
- 🤖 Integración con Gemini API (IA)
- 🗄 Base de datos PostgreSQL
- 🖼 Subida de archivos (imágenes)

Proyecto desarrollado con enfoque en arquitectura moderna y buenas prácticas.

---

# Arquitectura del Proyecto
- backend/ → API REST + WebSockets (NestJS)
- frontend/ → Cliente Web (Angular)

---

El backend y frontend cuentan con sus propios README técnicos generados por sus respectivos frameworks.

---

# 🧠 Tecnologías Utilizadas

## Backend
- NestJS
- PostgreSQL
- JWT (Autenticación)
- WebSockets (tiempo real)
- Gemini API (IA)
- Multer (subida de archivos)
- ConfigModule (variables de entorno)

## Frontend
- Angular
- Fetch API
- Manejo de JWT en LocalStorage
- Comunicación REST
- Conexión WebSocket

---

# Base de Datos

- PostgreSQL
- Manejo relacional de datos
- Persistencia segura de información
